# Product problems

Product refusals are not HCS errors. Their type is this page's HTTPS URL followed by the slug below. Each object contains `type`, `title`, `status` and `detail`. HTTP uses `application/problem+json` and retains the `error` alias for the review page. HTTP statuses are unchanged. CLI failures with `--json` are printed to stderr; successes print to stdout. MCP tool refusals retain their text and `isError`, with the problem object in `structuredContent`. MCP input-schema failures generated by the MCP SDK also carry an `invalid-input` problem in `structuredContent`. Per-candidate extraction refusals in MCP and CLI JSON retain their `reason` and add a `problem`; partial extraction still succeeds with exit 0. The book-access check deliberately gives the same answer for a hidden and an unknown book.

The status is the HTTP response status when applicable; a CLI or MCP problem carries the status appropriate to its refusal. CLI usage failures exit 2, other failures exit 1, and success exits 0.

| Slug | When | HTTP status | CLI exit |
| --- | --- | --- | --- |
| `unknown-book` | A book is missing or inaccessible | 404 where exposed | 1 |
| `not-found` | A route or resource is missing | 404 | 1 |
| `quote-not-literal` | A quote or replacement passage is absent or ambiguous | 409 where exposed | 1 |
| `stale-evidence` | Evidence is stale or a proposal's base has changed | 409 | 1 |
| `conflict` | An operation conflicts with current state | 409 | 1 |
| `invalid-input` | Input or a CLI command is invalid | 400 | 1 or 2 for usage |
| `unauthorized` | Authentication is missing or invalid | 401 | not applicable |
| `forbidden` | The host is not permitted | 403 | not applicable |
| `method-not-allowed` | HTTP method is not supported | 405 | not applicable |
| `body-too-large` | The request exceeds the body limit | 413 | not applicable |
| `internal-error` | An unexpected server error occurred | 500 | not applicable |

## unknown-book
A missing or inaccessible book is deliberately indistinguishable.

## not-found
The route or requested resource does not exist.

## quote-not-literal
The requested quotation or passage is absent or ambiguous.

## stale-evidence
The evidence or proposal base no longer matches the current scene.

## conflict
The requested operation conflicts with current state.

## invalid-input
The input, command or option is invalid.

## unauthorized
Authentication is missing or invalid.

## forbidden
The requested host is not permitted.

## method-not-allowed
The HTTP method is unsupported for the route.

## body-too-large
The request body exceeds the server limit.

## internal-error
An unexpected server error occurred.

## HCS failures
HCS failures instead use `urn:hcs:error:<code>` on HTTP, with `hcsError` and, for multiple errors, `x-rewrite-errors`. MCP carries the first HCS object in JSON-RPC `error.data.hcsError`; CLI JSON carries the first HCS object directly.
